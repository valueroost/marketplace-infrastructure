# NOTICE

This repository is a **public technical overview** of ValueRoost marketplace infrastructure.

It describes product concepts, high-level architecture, developer integration patterns, and reference implementations using **public-safe facts only**.

## What is included

- Conceptual documentation and diagrams
- High-level developer flow descriptions
- Public-facing screenshots curated for safety
- A conceptual basic-integration example outline

## What is not included

- Production application source code
- Smart contract source code
- Backend or private frontend source

- API secrets, signer keys, or deployment keys
- Internal audit attack details or exploit write-ups
- Database schema internals

Current public deployment target described here is **Base Sepolia** (testnet). **Mainnet is not launched.** Testnet settlement uses **mock USDC**. Real **Circle USDC** on mainnet and **CCTP** are planned.

Production systems and private repositories remain the source of truth for implementation detail.
